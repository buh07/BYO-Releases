# BYO Releases

Public download home for the **BYO installer** (Rust `byo` launcher + compiled firmware MCP sidecar + workflow pack).

## Latest
See [Releases](https://github.com/buh07/BYO-Releases/releases). Each release attaches a per-OS archive, its `.sha256`, and the `install.sh` / `install.ps1` bootstrap scripts.

> Preview builds are **unsigned** and meant for offline `--bundle` install (see the release notes). Signed builds with the one-command `curl | sh` installer and auto-update are coming.
